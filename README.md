# Zinnia Interiors

A modern, responsive single-page website for **Zinnia Interiors**, an interior design firm focused on residential interiors, renovation planning, and furnishing services. The website combines architectural-inspired aesthetics with elegant typography and interactive user experience elements.

## Overview

Zinnia Interiors is a premium interior design showcase website designed to present the firm's philosophy, services, design process, portfolio, client testimonials, and contact information. The site uses a blueprint-inspired visual identity, featuring custom color palettes, architectural motifs, and smooth scrolling interactions.
